# Ares Mimarlık — Kolay yükleme sürümü

Bu sürümde bütün dosyalar aynı klasördedir. Alt klasör bulunmaz ve gerekmez.

1. ZIP dosyasını bilgisayarınızda açın.
2. Çıkan klasörün içine girip bütün dosyaları seçin.
3. GitHub deposunun ana dizininde Add file → Upload files ekranına bırakın.
4. Aynı adlı eski dosyaların üzerine yeni dosyaları kaydedin.
5. Pages yayınının tamamlanmasını bekleyin, ardından siteyi yenileyin.

index.html, style.css, main.js, fotoğraflar, yazı tipleri ve proje sayfalarının tamamı deponun ana dizininde yan yana bulunmalıdır. Eski assets veya ares-mimarlik klasörleri bu sürüm tarafından kullanılmaz; düzeltme için bunları silmeniz gerekmez.

HTML, CSS ve yalın JavaScript. Kurulum, derleme veya API anahtarı gerekmez. GitHub Pages depo alt dizinleri desteklenir.

Stüdyo ve projeler kurgusaldır. Gerçek iletişim bilgisi sağlanmadığından Proje Görüşmesi bağlantısı alıcısı boş bir e-posta taslağı açar. Görsel kaynakları kaynaklar.html sayfasında, yazı tipi lisansları OFL.txt dosyalarındadır.
